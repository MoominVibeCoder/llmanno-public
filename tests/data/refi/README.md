# REFI-QDA-Schemas

Offizielle XML-Schemas des REFI-QDA-Standards (Rotterdam Exchange Format Initiative,
www.qdasoftware.org), MIT-Lizenz (Hinweis in den Dateien):

- `Project-mrt2019.xsd`: REFI-QDA Project, Release vom 18. März 2019
- `Codebook-mrt2019.xsd`: REFI-QDA Codebook, Release vom 5. Oktober 2017

Die Download-Seite (qdasoftware.org, „Project Implementation Files“) verlinkt eine
Tresorit-Freigabe. Die Dateien hier stammen aus öffentlichen Kopien, die bis auf
Leerraum übereinstimmen (vier von fünf geprüften Kopien), in LF-Zeilenenden.
Die Tests validieren jeden Export dagegen.
